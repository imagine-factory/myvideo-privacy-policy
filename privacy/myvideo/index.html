Privacy Policy

How MyVideo handles your data

Last updated September 5, 2026 · 최종 수정 2026년 9월 5일

Summary

MyVideo has no server, collects no analytics, and shows no ads. Your videos, file names, folder structure, and viewing activity are never sent to the developer or any third party. Data either stays on your device, or travels directly between your device and storage you configure yourself — your device's local storage, or a NAS/WebDAV/SMB server you provide the address and credentials for.

MyVideo ("the App") is a video library and player app. This policy explains what data the App accesses and how it is handled.

Data stored only on your device

The following stays in the App's private storage on your device and is never transmitted to the developer:

  • Library metadata — titles, folder structure, thumbnails generated from your videos, and your "My List" organization.
  • Playback history — resume position and watched/completed status for each video, so you can continue where you left off.
  • Server connection details — the address, username, and password you enter for a NAS/WebDAV/SMB server. Passwords are encrypted using the Android Keystore before being saved.
  • Secure Folder PIN — if you enable the optional Secure Folder feature, your PIN is stored as a salted hash. It cannot be recovered or reversed; losing it means the Secure Folder cannot be unlocked (by design — see the in-app warning shown when you set it up).
  • App settings — playback preferences, remote/keyboard button mapping, subtitle style, and similar preferences.

None of the above is backed up to any developer-controlled server. (Android's built-in "Auto Backup," which can copy app data to the user's own Google Drive, is separately excluded for Secure Folder data — see the in-app Secure Folder notice for details.)

Connections you configure yourself

MyVideo can connect to a NAS, WebDAV, or SMB server that you register yourself, using the address and login you provide. These connections go directly from your device to that server — the developer has no access to that server, its contents, or the credentials you use to reach it.

If you use Google Cast to send video to a TV or speaker, MyVideo uses Google's Cast SDK to communicate with the Cast device on your local network. This does not involve the developer's infrastructure.

Permissions used

Storage / mediaTo find and play videos stored on your device.
Network accessTo connect to the NAS/WebDAV/SMB servers you register, and to cast to Google Cast devices.
Wake lockTo keep playback running while the screen is off (e.g., audio-only background playback).

Children's privacy

MyVideo is not directed at children and does not knowingly collect information from children. The App has no account system and no data collection mechanism through which such information could be gathered.

Changes to this policy. If MyVideo's data practices change — for example, if a future update adds an optional account-based sync feature — this policy will be updated before that feature is released, describing exactly what new data is involved and how it's protected.

Contact

Questions about this policy can be sent to support@imaginefactory.kr.

기기 안에만 저장되는 정보

아래 항목은 앱의 기기 내부 저장 공간에만 남고 개발자에게 전송되지 않습니다:

  • 라이브러리 메타데이터 — 제목, 폴더 구조, 동영상에서 자동 추출한 썸네일, "마이 리스트" 구성.
  • 재생 기록 — 이어보기 위치, 시청 완료 여부(각 영상별).
  • 서버 연결 정보 — NAS/WebDAV/SMB 서버 등록 시 입력한 주소·아이디·비밀번호. 비밀번호는 Android Keystore로 암호화한 뒤 저장됩니다.
  • 보안 폴더 PIN — 보안 폴더 기능을 켰다면, PIN은 솔트를 더한 해시로만 저장됩니다. 복구·역산이 불가능하며, 분실 시 보안 폴더를 열 수 없습니다(의도된 설계 — 최초 설정 시 앱 내 경고 문구로 안내됨).
  • 앱 설정 — 재생 관련 설정, 리모컨/키보드 버튼 매핑, 자막 스타일 등.

위 항목은 어느 것도 개발자가 관리하는 서버로 백업되지 않습니다(안드로이드 기본 "자동 백업" 기능으로 사용자 본인의 구글 드라이브에 앱 데이터가 올라갈 수 있는데, 보안 폴더 관련 데이터는 이 백업 대상에서 별도로 제외됩니다 — 자세한 내용은 앱 내 보안 폴더 안내 참고).

사용자가 직접 설정하는 연결

MyVideo는 사용자가 직접 등록한 주소·계정정보로 NAS/WebDAV/SMB 서버에 연결할 수 있습니다. 이 연결은 사용자의 기기에서 그 서버로 곧바로 이루어지며, 개발자는 그 서버나 그 안의 내용, 접속에 쓰인 계정정보에 전혀 접근할 수 없습니다.

구글 캐스트로 TV나 스피커에 영상을 보낼 때는 구글의 Cast SDK를 이용해 같은 네트워크 안의 캐스트 기기와 통신합니다. 이 과정에도 개발자 쪽 서버는 관여하지 않습니다.

MyVideo는 아동을 대상으로 하지 않으며, 아동의 정보를 의도적으로 수집하지 않습니다. 계정 시스템도, 정보를 수집할 수단 자체도 없습니다.

변경 사항. MyVideo의 데이터 처리 방식이 바뀌면(예: 이후 버전에 계정 기반 동기화 기능이 선택적으로 추가되는 경우) 그 기능이 배포되기 전에 이 문서를 먼저 갱신하고, 어떤 정보가 새로 관여하며 어떻게 보호되는지 정확히 설명합니다.
